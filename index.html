HTML5: El Esqueleto de la Web

La quinta revisión del lenguaje fundamental para crear páginas web

¿Qué es HTML5?

HTML5 (HyperText Markup Language, versión 5) es la quinta revisión importante del lenguaje básico de la World Wide Web, HTML. Representa un cambio significativo con respecto a versiones anteriores, introduciendo nuevos elementos que mejoran la semántica, accesibilidad y multimedia.

Características Principales

  • Nuevos elementos semánticos como <header>, <footer>, <article> y <section>
  • Soporte integrado para audio y video con los elementos <audio> y <video>
  • Canvas y SVG para gráficos y animaciones
  • Mejor soporte para almacenamiento local (localStorage y sessionStorage)
  • Nuevos tipos de input para formularios (email, url, date, etc.)
  • Mejoras en rendimiento y seguridad
ejemplo.html 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Ejemplo HTML5</title>
</head>
<body>
  <header>
    <h1>Mi Página Web</h1>
    <nav>
      <ul>
        <li><a href="#inicio">Inicio</a></li>
        <li><a href="#servicios">Servicios</a></li>
      </ul>
    </nav>
  </header>
  
  <main>
    <article>
      <h2>Artículo Principal</h2>
      <p>Contenido interesante...</p>
      <video controls width="250">
        <source src="video.mp4" type="video/mp4">
      </video>
    </article>
  </main>
  
  <footer>
    <p>© 2023 Mi Website</p>
  </footer>
</body>
</html>

CSS3: El Estilo de la Web

Hojas de Estilo en Cascada que dan vida y diseño a las páginas web

estilos.css 
/* Variables CSS */
:root {
  --primary: #2563eb;
  --secondary: #8b5cf6;
  --gradient: linear-gradient(135deg, var(--primary), var(--secondary));
}

/* Flexbox para layout */
.container {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 2rem;
}

/* Grid para layout complejos */
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 2rem;
}

/* Animaciones y transiciones */
.card {
  background: white;
  padding: 2rem;
  border-radius: 12px;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.1);
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-5px);
  box-shadow: 0 15px 40px rgba(0, 0, 0, 0.2);
}

/* Media queries para responsive design */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
  
  .grid-container {
    grid-template-columns: 1fr;
  }
}

¿Qué es CSS3?

CSS3 (Cascading Style Sheets, nivel 3) es la última evolución del lenguaje de hojas de estilos, que permite controlar la presentación de los documentos HTML. CSS3 introduce múltiples módulos que añaden potentes capacidades de diseño.

Características Principales

  • Selectores avanzados para un control más preciso de los elementos
  • Flexbox y Grid para crear layouts complejos y responsive
  • Animaciones y transiciones para interfaces dinámicas
  • Variables CSS para mantener consistencia en el diseño
  • Sombras, gradientes y efectos visuales avanzados
  • Media queries para diseño responsive adaptado a diferentes dispositivos
  • Transformaciones 2D y 3D para efectos visuales impactantes

JavaScript: La Interactividad de la Web

El lenguaje de programación que hace dinámicas las páginas web

¿Qué es JavaScript?

JavaScript es un lenguaje de programación interpretado, dialecto del estándar ECMAScript. Se define como orientado a objetos, basado en prototipos, imperativo, débilmente tipado y dinámico. Se utiliza principalmente del lado del cliente, implementado como parte de un navegador web permitiendo mejoras en la interfaz de usuario y páginas web dinámicas.

Características Principales

  • Lenguaje del lado del cliente que se ejecuta en el navegador
  • Manipulación del DOM para cambiar contenido y estructura de páginas web
  • Gestión de eventos para interactuar con las acciones del usuario
  • Comunicación asíncrona con servidores (AJAX)
  • Almacenamiento en el lado del cliente (cookies, localStorage)
  • ES6+ introdujo clases, módulos, arrow functions y muchas mejoras
  • Node.js permite ejecutar JavaScript en el servidor
script.js 
// ES6+ Features: Arrow functions, const/let, template literals
const API_URL = 'https://api.example.com/data';

// Función asíncrona para obtener datos
const fetchData = async () => {
  try {
    const response = await fetch(API_URL);
    const data = await response.json();
    displayData(data);
  } catch (error) {
    console.error('Error:', error);
  }
};

// Manipulación del DOM
const displayData = (data) => {
  const container = document.getElementById('data-container');
  
  // Crear elementos con template literals
  const html = data.map(item => `
    

      
${item.title}

      
${item.description}

      
    

  `).join('');
  
  container.innerHTML = html;
};

Frameworks Modernos

Herramientas que facilitan el desarrollo de aplicaciones web complejas

React

Biblioteca de JavaScript para construir interfaces de usuario, desarrollada por Facebook. Utiliza un enfoque basado en componentes.

  • Virtual DOM para mejor rendimiento
  • Componentes reutilizables
  • JSX para escribir HTML dentro de JavaScript
  • Comunidad muy grande y activa

Vue.js

Framework progresivo de JavaScript para construir interfaces de usuario. Diseñado para ser adoptable incrementalmente.

  • Sistema reactivo de datos
  • Sintaxis de plantillas intuitiva
  • Curva de aprendizaje suave
  • Documentación excelente

Angular

Platform y framework para construir aplicaciones web client-side usando HTML y TypeScript, desarrollado por Google.

  • Framework completo (no necesita librerías adicionales)
  • Usa TypeScript por defecto
  • Inyección de dependencias
  • Potente CLI para generar código
